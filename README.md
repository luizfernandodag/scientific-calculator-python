# Scientific Calculator - Python

Simple scientific calculator built in Python to test:

- VS Code
- Codex
- AGENTS.md workflow
- Python environment
- Unit tests

## Version 1 Scope

Supported operations:

- addition
- subtraction
- multiplication
- division
- power
- square root
- sine
- cosine
- tangent
- logarithm base 10
- natural logarithm

## Out of scope

- GUI
- complex numbers
- graph plotting
- expression parser
- memory functions
